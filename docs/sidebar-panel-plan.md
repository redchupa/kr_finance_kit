# 사이드바 패널 업그레이드 계획 (v0.2.0)

> 목표: HA 사이드바에 **Finance Kit** 전용 화면을 추가해서, 대시보드 YAML 없이도
> 지수·환율·관심종목(주식/코인)·보유종목·공시를 한 화면에서 보고 관리한다.

## 1. 요구사항 → 구현 매핑

| 요구 | 구현 |
|---|---|
| 사이드바에서 사용 | `panel_custom` 로 `/finance-kit` 패널 등록 (아이콘 `mdi:finance`) |
| 첫 설치 시 빈 화면 방지 | 종목 칸을 모두 비우면 예시 종목 자동 추가 (설치 폼 체크박스, 기본 켜짐) |
| 주식·비트코인 종목 추가 | 헤더 오른쪽 위 ＋ 버튼 → 시장(🇰🇷/🇺🇸/🪙코인/기타) 선택 + 검색 → 옵션에 머지 저장 → 자동 리로드 |
| 톱니바퀴 커스텀 | ⚙️ 설정 시트: 테마·레이아웃·상승색·섹션 순서/표시·스파크라인·새로고침 주기·언어 |
| 카드 테마/레이아웃 10가지+ | 테마 13종 × 레이아웃 6종 (78 조합) |
| 모바일 가독성 | 1열 반응형, 큰 숫자 + tabular-nums, 44px 터치 타깃, safe-area 대응 |
| 모바일 편의 | 하단 탭바, 플로팅 ➕ 버튼, 바텀시트 설정/상세, 사이드바 햄버거 버튼 |
| 영어 전환 버튼 | 헤더 `KO / EN` 토글 (기본값 = HA 사용자 언어) |

## 2. 아키텍처

```
custom_components/kr_finance_kit/
├── panel.py          # 패널·정적경로 등록 + websocket 명령 (HA 의존)
├── panel_data.py     # 스냅샷 빌더·설정 검증·관심종목 편집 (HA-free, 단위 테스트)
└── frontend/
    └── kr-finance-panel.js   # 빌드 없는 단일 Web Component (Shadow DOM)
```

### Websocket 명령

| 명령 | 권한 | 역할 |
|---|---|---|
| `kr_finance_kit/snapshot` | 사용자 | coordinator 메모리 데이터 → 패널용 JSON (네트워크 호출 없음) |
| `kr_finance_kit/history` | 사용자 | 스파크라인/차트용 종가 배열 (yfinance, 서버 캐시 15~60분) |
| `kr_finance_kit/search` | 사용자 | 종목 검색 (OpenDart 기업목록 한글명 + Yahoo 검색) |
| `kr_finance_kit/watchlist/add` · `remove` | **관리자** | 옵션에 티커 추가/삭제 (spread 머지, 다른 옵션 보존) |
| `kr_finance_kit/prefs/get` · `set` | 사용자 | 사용자별 화면 설정 (HA Store, 기기 간 동기화) |

보유종목(수량·평단) 입력은 기존 `add_position` / `remove_position` 서비스 재사용.

### 설계 원칙 (기존 함정 재발 방지)

- 옵션 저장은 **항상 `{**entry.options, key: new}` spread** — allow-list 재구성 금지 (v0.1.55 사건).
- 설정 읽기는 **`{**data, **options}` 머지** — `options or data` 금지 (v0.1.56 사건).
- 화면 설정(테마 등)은 config entry 가 아닌 **별도 Store** → 옵션 플로우가 덮어쓰지 않음.
- 패널은 엔트리 리로드(종목 추가 시)에도 유지, 엔트리 **삭제** 시에만 제거.
- 스냅샷은 메모리 데이터만 — Yahoo 추가 호출 없음. 차트만 별도 캐시.

## 4. 투자자 편의 기능 (이번 버전 포함)

- 장 상태 칩 + **개장/마감 카운트다운** (KR·US)
- **김치 프리미엄** 자동 계산 (`BTC-KRW` + `BTC-USD` + USD/KRW 가 있을 때)
- **보유 비중 바** (포트폴리오 구성비), 종목별 손익률
- 52주 고가/저가 대비 위치 바 (상세 속성 켜진 경우)
- 종목 탭 → 상세 시트 (기간별 차트 1D/5D/1M/6M/1Y, 보유 입력, HA 기록 열기)

## 6. 다음 단계 아이디어 (투자자 관점 제안)

우선순위 = 체감 가치 ÷ 구현 비용. 모두 무료 데이터 소스로 가능.

| # | 아이디어 | 왜 유용한가 | 데이터/구현 |
|---|---|---|---|
| 1 | **목표가·손절가 알림** | 가장 많이 쓰는 기능. 상세 차트에 가로선 + 도달 시 HA 알림 | 패널 prefs에 가격선 저장 → coordinator 틱마다 비교 → `kr_finance_kit_price_target` 이벤트 |
| 2 | **환차손익 분리 (미국 주식)** | 원화 기준 수익 중 "주가 덕"과 "환율 덕"을 나눠 보여줌 — 국내 서학개미 핵심 관심사 | `add_position` 에 선택 필드 `avg_fx`(매수 시 환율) 추가 → 순수 계산 |
| 3 | **업비트 원화 시세 직접 연동 + 코인 보유 입력** | 야후에 없는 원화 코인, 더 정확한 김프, 코인 손익까지 포트폴리오에 합산 | 업비트 공개 시세 API (키 불필요) |
| 4 | **실적 발표일·배당락일 캘린더** | "D-3 실적 발표" 칩 + HA calendar 엔티티로 자동화 연결 | yfinance `calendar` / OpenDart 정기공시 일정 |
| 5 | **공포·탐욕 지수 칩** | 시장 분위기를 숫자 하나로 — 요약 섹션에 표시 | 코인: alternative.me 무료 API |
| 6 | **중요 공시 키워드 필터** | 유상증자·자사주·최대주주 변경 등만 골라 푸시 → 알림 피로 감소 | OpenDart `report_nm` 키워드 매칭 |
| 7 | **KRX 휴장일 반영** | 개장 카운트다운·폴링 주기 정확도 | KRX 휴장일 목록 (연 1회 갱신) |
| 8 | **대시보드용 카드 (finance-kit-card)** | 패널의 카드/히트맵을 기존 대시보드·벽패드에도 삽입 | 같은 JS 재사용, Lovelace custom card 등록 |
